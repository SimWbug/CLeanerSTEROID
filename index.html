⚙️ GUIDE

Installer la map via CurseForge

Le pack de mods CleanGang doit déjà être installé sur ton launcher. Voici comment y ajouter la map de la saison 2.

Ouvre CurseForge

Lance l'application CurseForge et va dans l'onglet Minecraft à gauche.

Repère le profil CleanGang

Dans la liste de tes instances, trouve le profil CleanGang Server Pack déjà installé.

Ouvre le dossier du profil

Clique sur les trois petits points ⋯ à côté du profil, puis sur Open Folder (ou « Ouvrir le dossier »). Ça ouvre l'explorateur de fichiers directement dans le dossier de l'instance.

Va dans le dossier « saves »

Dans la fenêtre qui s'est ouverte, entre dans le dossier saves. C'est là que Minecraft range tous les mondes du profil.

Télécharge et décompresse la map

Clique sur « Télécharger la map » plus haut sur cette page, puis décompresse l'archive .zip téléchargée (clic droit → Extraire tout).

Glisse le dossier dans « saves »

Fais glisser le dossier décompressé (celui qui contient level.dat) directement dans le dossier saves ouvert à l'étape précédente.

Lance le jeu et sélectionne le monde

Retourne sur CurseForge, clique sur Play pour lancer le profil CleanGang. Une fois dans le jeu, va dans Jouer à un jeu solo et sélectionne la map de la saison 2 dans la liste.
